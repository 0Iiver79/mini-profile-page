# Mini Página “Sobre Mim”

## 🎯 Objetivo
Este projeto é uma **mini página pessoal** criada com HTML e CSS, com o objetivo de praticar:

- Criação de uma página HTML do zero  
- Uso de **tags semânticas** (`header`, `main`, `section`, `footer`)  
- Aplicação de **cores de fundo diferentes** para cada seção  
- Estilização com **propriedades básicas de CSS** (`background-color`, `font-family`, `color`, `text-align`, `font-size`)  
- Construção de um **carrossel de imagens** para hobbies  

---

## 📝 Estrutura do Projeto

O projeto contém:

1. **index.html** – página principal  
2. **styles.css** – estilos da página  
3. **img/** – imagens usadas no carrossel e perfil  

### Seções da página

- **Header:** Título e menu de navegação  
- **Sobre Mim:** Breve apresentação com imagem de perfil  
- **Meus Hobbies:** Carrossel de fotos mostrando hobbies  
- **Contato:** Links para GitHub, LinkedIn e formulário de contato  
- **Footer:** Nome e ano  

---

## 🎨 Tecnologias e Conceitos Aplicados

- HTML semântico (`header`, `main`, `section`, `footer`)  
- CSS básico: cores, fontes, alinhamento e sombras  
- Carrossel de imagens com animação CSS  
- Responsividade básica com flexbox  
- Links externos com efeito hover
